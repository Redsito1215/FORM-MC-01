## 📌 Descripción

Este repositorio contiene el mapa conceptual digital sobre el **ecosistema de sistemas distribuidos**, elaborado colaborativamente como actividad formativa preparatoria para la **PE-U1** y la **EXP-1**.

El mapa presenta definiciones breves, relaciones explícitas entre conceptos y referencias bibliográficas recientes y verificables.

## 🎯 Objetivo

Organizar visualmente los principales componentes de los sistemas distribuidos, mostrando sus características, clasificaciones, mecanismos de comunicación y relaciones fundamentales.

---

## 🧠 Contenido del mapa

El mapa conceptual desarrolla los siguientes temas:

- 🌍 Ecosistema de sistemas distribuidos
- 🖥️ Tipos de sistemas distribuidos
- ☁️ Computación en la nube, *edge* y *grid*
- 🔗 Middleware
- 📡 Modelos de comunicación síncronos y asíncronos
- 👁️ Transparencia de acceso, ubicación, replicación, concurrencia, migración y fallos
- 🛡️ Tolerancia a fallos
- ♻️ Replicación, redundancia y *failover*
- ⚖️ Teorema CAP
- 🗃️ Consistencia, disponibilidad y tolerancia a particiones
